Understanding the terms

What each figure means, and how it is calculated
BAC · Budget
BAC = Σ all activity costs
—
Total planned cost of the IPT. The baseline for everything else.
PV · Planned Value
PV = BAC × planned %
—
Value of work that should be done by this period.
EV · Earned Value
EV = BAC × measured %
—
Value of work actually completed. Uses PV until you enter a measured %.
AC · Actual Cost
AC = total spend to date
—
Money actually spent on the IPT up to this period.
SPI · Schedule
SPI = EV ÷ PV
—
1.00 = on schedule. Below 1.00 = behind plan.
CPI · Cost
CPI = EV ÷ AC
—
1.00 = spend matches value earned. Below 1.00 = overspending.
EAC · Forecast Cost
EAC = BAC ÷ CPI
—
Forecast total cost of the IPT if the current CPI continues.
VAC · Variance
VAC = BAC − EAC
—
Negative = forecast overrun against the budget.
Method. PV = Total Budget × planned cumulative %. EV = Total Budget × measured % complete (defaults to PV %). AC = cumulative actual cost. SPI = EV ÷ PV · CPI = EV ÷ AC · SV = EV − PV · CV = EV − AC · EAC = BAC ÷ CPI · VAC = BAC − EAC. Colour: green at 1.00 or above, amber from 0.90 to 0.99, red below 0.90.
